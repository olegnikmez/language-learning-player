Руководство пользователя: Плеер для изучения языков

Добро пожаловать в руководство по настройке и использованию интерактивного веб-плеера для изучения иностранных языков методом чтения и погружения. Инструкция охватывает запуск локального сервера Anki, настройку искусственного интеллекта, управление плеером и горячие клавиши.

1. Установка и настройка AnkiConnect

Плеер умеет сохранять разобранные карточки прямо в ваше десктопное приложение Anki с помощью плагина AnkiConnect.

Шаг 1: Установка плагина в Anki

  1. Запустите настольную программу Anki на вашем компьютере.
  2. В верхнем меню перейдите в раздел: Инструменты → Дополнения (Tools → Add-ons).
  3. Нажмите кнопку «Получить дополнения...» (Get Add-ons...).
  4. В появившемся окне введите цифровой код плагина: 2055492159 и нажмите OK.
  5. После завершения загрузки обязательно перезапустите Anki, чтобы плагин активировался.

Шаг 2: Настройка CORS (разрешение доступа для плеера)

Поскольку плеер может запускаться как локально, так и через GitHub Pages, локальный сервер Anki должен знать, какому сайту разрешено отправлять запросы.

  1. В Anki зайдите в Инструменты → Дополнения.
  2. Кликните по строке AnkiConnect и нажмите кнопку «Настройки» (Config) справа.
  3. В открывшемся JSON-файле найдите параметр webCorsOriginList и добавьте туда адрес вашего сайта (например, ваш GitHub Pages или http://localhost), чтобы получилось так:
{
    "apiKey": null,
    "apiLogPath": null,
    "ignoreOriginList": [],
    "webBindAddress": "127.0.0.1",
    "webBindPort": 8765,
    "webCorsOriginList": [
        "http://localhost",
        "https://olegnikmez.github.io",
        "https://goodsforall.com.ua"
    ]
}
Важно: Программа Anki должна быть всегда запущена в фоновом режиме во время работы с плеером, так как локальный сервер плагина работает на адресе http://127.0.0.1:8765.

2. Настройка API-ключа и инструкций DeepSeek

Для лингвистического разбора предложений используется нейросеть DeepSeek. Настройки сохраняются локально в памяти вашего браузера (localStorage).

  1. Откройте плеер в браузере. В левой боковой панели найдите развертывающийся блок «Настройки нейросети (DeepSeek)».
  2. В поле API-ключ DeepSeek введите ваш секретный токен, начинающийся с sk-... (его можно получить на официальном сайте платформы DeepSeek).
  3. В поле Инструкция нейросети задан системный промпт по умолчанию. Вы можете отредактировать его под свои задачи (не рекомендуется). Промпт по умолчанию:
Ты строгий лингвистический анализатор. ЗАПРЕЩЕНО использовать любые приветствия, вводные, оценочные или заключительные фразы. Начинай ответ СТРОГО с литературного перевода.

Раздели предложение на короткие логические смысловые блоки (словосочетания, идиомы, грамматические конструкции, предложные группы или отдельные сложные слова). Не дроби неделимые фразы.

Выводи ответ строго по этой структуре:

Литературный перевод:
[Полный перевод фразы]

**Разбор:**

**[Смысловой блок]** — [его точное значение именно в этом предложении]
* [Краткое грамматическое пояснение: только самое важное для понимания (начальная форма, падеж, время, управление, тип склонения), краткий перевод каждого слова в контексте 
**[слово]** - (перевод). Без избыточных деталей, каждое слово с новой строки, но без абзаца или пункта]
***
Продолжай этот шаблон для каждого смыслового блока в предложении.

3. Работа с плеером и добавление карточек в Anki

Загрузка медиафайлов

  • Видео / аудио: Нажмите на соответствующую кнопку в левой панели и выберите файл мультимедиа.
  • Субтитры: Загрузите файл основных субтитров в формате .srt и, при необходимости, файл с переводом.

Интерактивные иконки в субтитрах

Когда воспроизводится видео, каждое слово в строке субтитров интерактивно:

  • Клик по слову (ЛКМ): Озвучивает слово на выбранном исходном языке с помощью системного синтезатора речи браузера.
  • Иконка Google Translate (буква А / 文): Показывает быстрый контекстный перевод и альтернативные варианты в правой панели.
  • Иконка Нейросети (значок AI/бота): Отправляет всё предложение в DeepSeek. При этом боковая панель фиксируется («замораживается»), чтобы вы могли спокойно изучать разбор и не бояться случайных смещений мыши. Снять фиксацию можно клавишей Esc.
  • Иконка Anki (плюс в квадрате): Позволяет в один клик перенести всё предложение и его перевод из нижнего субтитра во всплывающее окно редактора карточки перед отправкой в базу Anki.

Создание колод и моделей

Перед началом добавления карточек разверните в левом меню блок «Инструменты (Anki и Текст)» и нажмите:

  1. Anki - создать колоду: Автоматически сформирует и зарегистрирует колоду в Anki на основе выбранных в меню языков.
  2. Создать модель: Создаст правильную структуру полей (Word, Translation, Sentence, Sentence_Translation) и шаблон карточки.

4. Горячие клавиши управления

Для максимального удобства при обучении используйте клавиатурные сокращения:

  • A — Проиграть предыдущий фрагмент субтитров
  • D — Перейти и проиграть следующий фрагмент
  • S — Повторить текущий фрагмент заново
  • X или E — Пауза / Воспроизведение (Stop / Play)
  • Q — Показать / скрыть основные субтитры
  • W — Показать / скрыть блок перевода
  • H — Скрыть / показать правую панель со списком всех субтитров
  • M + движение мыши — Перемещение блоков субтитров по экрану
  • ESC — Закрыть панель разбора нейросети или всплывающее окно редактора Anki
  • Ctrl + R — Сбросить настройки и перезагрузить приложение
Совет по редактору карточек Anki: Внутри модального окна редактирования карточки вы можете использовать сочетание Ctrl + L для быстрого создания списков с маркерами точек, а также Shift + Enter для переноса строк без создания новых пунктов.
